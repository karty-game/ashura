# Procedural impostor regression fixture

This build-only package owns the deterministic opaque tree generator and its
[golden GLB](testdata/gnarled-tree.glb). It is independent of the gallery's
three downloaded impostor comparison models.

The regression test compares generated bytes with the golden file and checks
26,740 triangles, 17,624 vertices, four material primitives, material bounds,
unit normals and triangle winding through the real GLB compiler.

To intentionally regenerate the golden file, run from the repository root with
the pinned toolchain:

```sh
mise exec -- go -C internal/impostorfixture run generate.go
```

The handwritten generator is excluded from ordinary package builds. Normal
sample builds neither read this fixture nor regenerate it. Keep the generator,
golden file and assertions together when deliberately changing fixture topology.
